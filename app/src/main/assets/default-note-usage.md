## 它是什么

MOSS 笔记是一个语音笔记本：按「开始通话」跟它说话，聊完让它把这一通整理成一篇笔记，存进手机本地。

## 一次完整的使用

- 点底部「开始通话」，第一次会让你允许录音和通知。
- 说话就行，随时可以打断它；中间的球会跟着声音起伏，谁在说话一眼能看出来。
- 说「帮我把刚才聊的生成笔记」，它就把这一通整理成一篇。
- 不想说话也可以：点笔记区右上角「＋ 生成笔记」，把这一通从头整理一遍。

## 聊完怎么挂断

点「挂断」。如果这一通还没出笔记，会先问一句要不要整理再挂断——整理在后台跑，挂断不影响结果，可以直接选「先整理再挂断」。

## 管理笔记

- 点开一篇：右上角依次是 复制 / 编辑 / 分享 / 导出 / 删除，删除在最右端，避免误触。
- 列表里向左滑一张卡片也能删除，删除前还会再确认一次。
- 顶部放大镜按标题或正文搜索。
- 「＋ 生成笔记」**长按** = 不看有没有新内容，把这一通重新整理一遍。
- 「导出」把 Markdown 存到手机的 `下载/MOSS笔记/` 目录。

## 继续聊

打开一篇笔记，点底部「继续聊」，这篇会带进下一通对话；聊完保存时是在原文上整篇改写，不会另起一篇。

## 设置

- **API Key**：换 key 或额度到期时在这里粘一次，保存即生效，不用重装。
- **整理笔记的模型**：可选，笔记可以交给 MiniMax / DeepSeek / 智谱 GLM / 通义千问 等任意 OpenAI 兼容服务整理——在设置里选提供商、填那一家的 key（模型名和接口地址都能改）；不填 key 就用本地规则整理，不联网。
- **上行音频**：系统降噪与上行增益，下一通通话生效。对方老是听不清时先试试调增益。
- **调试日志**：打开后主界面会显示最近一句识别结果。
- **存储自测**：写入一篇测试笔记，用来确认落盘和列表刷新都正常。

## 数据在哪

笔记是 App 私有目录里的 Markdown 文件，卸载 App 会一并清空。重要的笔记记得用「导出」或「分享」留一份。
